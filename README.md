# AI Job Application Assistant

An AI Agent Skill that helps job seekers prepare honest, tailored job applications from a real job description.

## What it helps with

- Understand a job description and identify important requirements and keywords.
- Improve a CV using only the user's real education, skills, and experience.
- Draft a job-specific cover letter.
- Prepare likely interview questions and sample answers.
- Review an application for clarity, grammar, and consistency.

## Important

This skill must not invent qualifications, work experience, achievements, or skills. It does not guarantee interviews or job offers. Users should avoid sharing passwords, identity numbers, or other sensitive information.

## Use it

This repository contains an Agent Skill, not a standalone website or chatbot. To use it, install or copy the skill into an AI agent that supports the Agent Skills format.

With a compatible GitHub CLI version, an example install command is:

```bash
gh skill install harmainsharifain90-cpu/Ai-job-application-assistant ai-job-application-assistant
```

Check the agent's documentation for its supported skill location and installation method.

## Example request

"Here is a job description and my real background. Identify the requirements, then help me tailor my CV and write a cover letter. Ask me about missing details instead of making anything up."
